# FS-01: free hosted activation

Status: implementation started. Signup stays disabled. No policy draft is
published by this change.

## Scope

First prove the pinned WorkOS SDK retry behavior and concurrent organization
creation in Staging. Require one identifiable creation winner and durable
acceptance metadata before implementing the grant.

Then add an identity-only signup form and a guarded activation POST. Any verified
email may qualify. An explicit agreement creates one personal workspace with
User access only. Use the existing free billing implementation and preserve
existing access. Retained organization records prevent automatic grant replay.

Use a default-off server setting. Private legal text stays outside the image;
an approved, complete document bundle is required before enabling activation.
Unknown writes require reconciliation, never a blind membership-create retry.

## Acceptance and verification

Write the failing acceptance scenarios before implementation. Cover disabled
signup, verified identity, exact agreement, stale or forged forms, concurrency,
restart and unknown outcomes, inherited roles, and preservation of removed
access. Record provider proof, required local gates, and remaining release work
here before the pull request is Ready.

Portal/native MCP handoff, marketing changes, policy publication, and opening
production signup are later tickets.
