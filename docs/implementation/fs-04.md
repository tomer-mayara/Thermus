## Scope

Connect the approved document bytes to hosted production composition. Keep the
single `SELF_SERVE_SIGNUP_ENABLED` switch off. Prepare normal marketing links to
the closed signup route and hosted portal, free early-access copy, and accurate
connection guidance in the separate marketing repository.

Keep current public policy pages unchanged. Retain publication artifacts outside
the website build so previews cannot publish the replacement text. Actual
publication, existing-user transition, and signup opening remain separate work.

## Acceptance specification

1. Given the production composition and disabled signup, when the process starts
   and a visitor requests signup, then it stays closed, reveals no new policy
   text, and makes no activation write.
2. Given enabled signup in a test environment, when the real production document
   source is loaded, then the complete approved terms, notice, and exact checkbox
   wording are available with the retained versions and hashes. Invalid bytes or
   hashes fail before signup can activate.
3. Given the rendered signup form, when a person reads it, then the complete
   documents are readable, the agreement checkbox is initially unchecked, and
   acceptance uses the displayed bundle version. No private operator notes,
   request records, or credentials are included.
4. Given the marketing page with JavaScript disabled, when Start subscription or
   Sign in is followed, then a normal link reaches the hosted signup or portal.
   The hosted offer is free, needs no card, and creates no automatic charge.
   Download/waitlist behavior and current public policy pages stay unchanged.
5. Given the publication artifacts, when the ordinary marketing build or a PR
   preview runs, then the new policies are absent from its published files.
   Artifacts identify the approved source bytes and the later publication steps.

Initial state: these scenarios are not yet met. Production supplies no signup
documents, marketing links still open the waitlist, and hosted pricing and
onboarding copy do not describe the implemented free service.
