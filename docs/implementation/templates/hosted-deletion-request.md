# Private hosted deletion request record

Copy this template into the restricted operator store, outside Git. Store only
needed metadata and safe references. Do not paste tokens, API keys, cookies,
invitation links/codes, raw provider responses, identity documents, full URLs
with query strings, fetched pages, or request content. Follow the
[deletion runbook](../hosted-account-deletion.md).

its scope, and the fact that deletion cannot be undone. After an unknown
outcome, record the inspection result before any retry.
