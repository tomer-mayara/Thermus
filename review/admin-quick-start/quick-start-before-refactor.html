2

Configure audit logs

Choose Axiom or Custom. Enter an HTTPS OTLP/HTTP JSON logs endpoint and a Bearer token. For Axiom, also enter an Axiom dataset and use a token scoped to it. For Custom, leave the Axiom dataset empty.

  1. Keep Enable export off for the initial check, then select Test.
  2. Check your destination for the synthetic test event.
  3. Turn Enable export on and select Save for ongoing export.

Test saves settings, including the Enable export switch, before sending.

Open Audit Log

Either Save or Test can enable or disable export. Check the switch first. Test is optional and does not prove continued delivery or durable storage.

If Save fails or is unconfirmed, no Test is sent; read saved settings before another change. Failed Test does not undo saved settings; consult Audit logs help for recovery and token handling.

Logs can include tool inputs, results, errors, and administration metadata. Redaction cannot remove every secret from free text. Delivery is best effort: events can be lost or duplicated, with no history or replay. Check destination access and retention.
