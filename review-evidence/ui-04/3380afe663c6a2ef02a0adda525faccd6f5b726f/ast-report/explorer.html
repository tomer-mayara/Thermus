Reading guide

Ease of maintenance

Maintainability index, 0 to 128. Higher is better: it mixes size, complexity and comment density. Above 85 the file reads without effort.

Decision paths

Cyclomatic complexity: the number of independent routes through the code. Each one is another case to test. Under 5 per method stays comfortable.

Responsibilities

LCOM4: groups of methods that never share data. One group means one job. Several groups means several classes waiting to be extracted.

Lines of code

Logical lines: statements only, blank lines and comments excluded. It is the honest measure of how much there is to read.

Neighborhood

Files this one imports, and files that import it. Many incoming arrows mean every change here ripples outwards.

Severity of a risk

How far the file is from the rule threshold, not how urgent it is. Critical and high are worth a look; low is often noise.
