The last defines request/result, durable intent, terminal receipt and admit/read/complete outcomes. The [existing SQL adapter](https://github.com/tomer-mayara/Thermus/blob/b630a76275d5809a498ae63e1cbc322086f4194f/src/logs/audit/pg-destination-settings-store.ts#L17) implements it through short atomic statements and the existing bounded runtime. The additive private table changes shared stored data and recovery rules; applying its migration is separate from source integration.
